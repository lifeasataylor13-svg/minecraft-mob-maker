Export your model from Blockbench into THIS folder.

Steps:
1. In Blockbench: File -> Export -> Export Bedrock Geometry
2. Save it as:  glow_slug.geo.json
3. Put it right here in: glow_slug_RP/models/entity/

The model's identifier inside the file must be:  geometry.glow_slug
(That matches the "geometry" line in glow_slug_RP/entity/glow_slug.json)

You can delete this .txt file once your real model is here.
